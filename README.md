# Crowd Counting Using YOLOv8 Deep Learning

## Project Description
This project performs real-time object detection using the COCO dataset and deep learning techniques.

## Features
- Detects multiple objects
- Uses COCO dataset labels
- Real-time prediction
- Image-based object detection

## Technologies Used
- Python
- OpenCV
- YOLO
- NumPy

## Dataset
COCO Dataset

## Project Structure
code/           → project source code
dataset/        → dataset files
screenshots(images)/    → output screenshots

## How to Run
python Code.py
